# Release Notes

Incluir siempre:

- Resumen funcional orientado a usuarios.
- Resumen tecnico orientado a mantenimiento.
- Impacto en UI, datos, Firebase, seguridad y performance.
- Archivos o areas modificadas.
- Validacion ejecutada y resultados.
- Riesgos conocidos, flags, pendientes y aprobaciones necesarias.
- Pasos de rollback o mitigacion cuando el cambio sea riesgoso.

No afirmar que hubo deploy, QA visual o validacion completa si no se ejecuto.
